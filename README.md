# HR Analytics Dashboard

## Project Overview
Built an interactive HR Analytics Dashboard using Power BI to analyze employee attrition trends and workforce insights.

## Key Insights
- Research & Development has highest attrition
- Employees working overtime show higher attrition
- Younger employees show increased attrition trends

## Tools Used
- Power BI
- DAX
- Data Visualization
- Power Query

## Features
- KPI Cards
- Interactive Filters
- Department Analysis
- Attrition Analysis
- Overtime Insights
